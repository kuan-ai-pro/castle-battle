# Castle Battle - Almaty vs Shymkent

Вертикальная игра 3x4 на Phaser 3 для TikTok LIVE. Битва замков Алматы vs Шымкент.

[Gameplay Preview](https://via.placeholder.com/540x720.png?text=Add+Gameplay+GIF+Here)

### 🎮 Как запустить локально
```bash
npm install
npm run dev
```
Открой http://localhost:5173

Тест спавна без TikTok:
http://localhost:3001/test?type=almaty
http://localhost:3001/test?type=shymkent

### ⚔️ Механика от старта до победы

**Старт:** 2 замка по 2000 HP, счет кубков [0] - [0], поле чистое.

**Спавн:** 1 подарок = 1 рыцарь. Если прилетело 10 подарков за секунду - 10 рыцарей появляются СРАЗУ КУЧЕЙ у ворот, без очереди.

**Бой:**
- Рыцарь: 10 HP, урон 5 по рыцарю / 1 по замку, 1 удар/сек
- Приоритет: СНАЧАЛА ВРАГ в радиусе 30px, потом замок
- Стенка на стенку в центре, пробили - бьют замок

**Финал:** При HP < 400 - HP бар мигает, тряска камеры, надпись "БАШНЯ ПОД УГРОЗОЙ!"

**Комбо:** 5+ рыцарей за 5 сек = надпись КОМБО xN + скорость +50% на 5 сек. Только в комбо показывается лента доноров.

**Победа и рестарт:** HP замка 0 = взрыв, +1 к кубкам сверху, через 3 сек рестарт раунда. Кубки сохраняются.

### 🛠 Стек
Vite + Phaser 3 (как в Shapalak)
- `src/main.js` - создание игры
- `src/Knight.js` - логика рыцаря
- `src/Castle.js` - логика замка
- `src/config.js` - НАЗВАНИЯ ГОРОДОВ РЕДАКТИРУЮТСЯ ТУТ: ALMATY / SHYMKENT
- `giftMapping.json` - маппинг подарков

### 🔧 Конфиг городов
В `src/config.js` поменяй:
```js
TEAM_LEFT_NAME = "АЛМАТЫ"
TEAM_RIGHT_NAME = "ШЫМКЕНТ"
```
